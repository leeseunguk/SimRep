[P164] 이 장에서 배울 것

[P165] 사용자가 실제로 쓰는 데스크톱 앱의 흐름과, 쉽게 쓰도록 넣은 기능을 정리한다.

[P166] 앱은 Tauri 2와 React로 만들었고, 3D 화면은 WebGPU로 그린다. 계산은 2장의 Rust 코어를 그대로 부른다(docs/dev/frontend.md의 구조 요약 절). 시작 화면에서 einzel 렌즈, 정전기 4중극, 반사형 TOF, 이온 트랩 템플릿을 고르면 형상 만들기, 전위 풀기, 전압과 입자 정하기, 날리기를 차례로 따라갈 수 있다. 그림 19은 4중극 GEM 파일로 그 흐름을 실제로 따라간 화면 네 장이다. 첫째 장에서 가져오기 마법사가 GEM의 부품 세 개를 보여 주고 전극 번호와 전압(2.5 V, −2.5 V, 0 V)을 받는다. 둘째 장에서 cut-cell 격자를 만들고 전위를 풀어(135 ms, 표면이 지나는 점 11,160개) 비행 준비를 마친다. 셋째 장에서 정확한 표면으로 이온 1,000개를 날리고, 넷째 장에서 TOF 히스토그램과 도착한 곳별 이온 수(+X 경계 750, 전극 3에 230, 전극 2에 20)를 본다. 이 개수는 4.6절의 CLI 결과와 같다.

[C167] 그림 19. 앱의 처리 흐름: 가져오기 → 전위 풀기 → 비행 → 결과를 연속으로 캡처했다. 출처: figures/F03.png, 캡처 조건은 figure-ledger.json의 F03.

[P168] 쉬운 사용을 위해 다음을 넣었다. 처음 쓰는 사람을 위한 5단계 따라하기가 있고, 실제 템플릿으로 전압 조정, 비행, TOF 히스토그램, CSV 내보내기까지 진행한다. 그림 20은 그 둘째 단계로, 안내 상자가 집속 전극 슬라이더를 강조하고 전압을 바꾸면 무엇이 달라지는지 설명한다. 전압 슬라이더는 결과를 실시간으로 다시 계산한다(4.8절).

[C169] 그림 20. 앱의 5단계 따라하기 가운데 한 단계(한국어 화면). 출처: figures/F21.png.

[P170] 정확한 표면 파일이 있으면 카드와 배지로 보여 주고 스위치로 끌 수 있다. 그림 21는 같은 4중극에서 스위치를 켠 경우(정밀 모드, CPU 배정밀도)와 끈 경우(실시간 미리보기, GPU 단정밀도)를 나란히 놓은 화면이다. 켜면 이온 20개가 전극 2의 실제 표면에 닿고, 끄면 그 이온들이 격자점 계단을 지나 전극 3이나 경계로 가서 도착 분류가 750/230/20에서 751/249로 바뀐다. 결과 패널은 어느 모드로 계산했는지 배지로 함께 보여 준다. 그 밖에 되돌리기와 다시 하기, 1.5초마다 자동 저장, 한국어와 영어, 밝은 테마와 어두운 테마, 궤적과 결과 표의 연동 선택이 있다(docs/dev/frontend.md).

[C171] 그림 21. 정확한 표면 카드와 결과 배지. 표면 파일 이름, 켜고 끄는 스위치, 비행에 쓴 표면 종류를 보여 준다. 출처: figures/F22.png.

[P172] 설치 파일은 관리자 권한 없이 사용자 계정에 설치되는 NSIS 패키지다. 크기는 28.5 MiB이고, STEP 가져오기용 OpenCascade 라이브러리와 실행에 필요한 Visual C++ 런타임을 함께 담는다. 조용한 설치, 실행, STEP과 IGES 가져오기, 비행, 제거를 실제로 확인했다(docs/dev/frontend.md의 Windows 설치 패키지 절).

[P173] 요점 정리

[P174] 앱은 템플릿에서 결과까지 한 화면 흐름으로 이어지고, 따라하기, 실시간 슬라이더, 정확한 표면 표시, 한국어 화면을 갖췄다. 설치에 관리자 권한이 필요 없다.
