[P187] 결론에는 다음 조건이 붙는다. 첫째, 정확도 기준해는 촘촘한 격자로 얻은 수치 기준이며 연속 해의 엄밀한 상한이 아니다. 둘째, cut-cell은 전위에서 2차 정확도이지만 전극 표면 바로 옆 전기장은 약 1차이고 곡면 유전체와 자성체 경계도 약 1차다. 셋째, 유전체와 자기 포텐셜, 앱의 측정 일부는 다른 작업과 기계를 나눠 쓰는 동안 했다. 이 사실은 각 원본 문서에 표시했다. 넷째, 측정 장비는 RTX 3070 한 대이며 배정밀도가 빠른 GPU에서는 CPU와 GPU의 선택 기준이 달라진다.

[P189] 표 14에는 docs/PLAN.md, docs/magnetostatics.md, bench/fly-gpu.md, docs/mesh-io.md에 기록된 한계를 모았다. 이 가운데 자기장 GPU 비행은 배정밀도 연산이 빠른 GPU나 혼합 정밀도 방식으로 다시 볼 수 있고 정확한 표면의 GPU 비행은 메시 교차 계산을 GPU로 옮기면 된다.
