# Provenance of reference and answer-key files

Every committed data file that a benchmark record, validation figure, test
fixture or published claim in `docs/claims.json` compares against has one row
below, modelled on Iteration-CFD's `reference/PROVENANCE.md`. The table is
read by `tools/provenance_check.py`, which recomputes each `sha256` and fails
when a listed file is missing or changed; `tools/provenance_check.py --add
PATH` appends a row for a new file.

Columns: `file` is repo-relative; `origin` says where the bytes came from
(a command, a document, or `unknown` - never guessed); `date` is the
file's first commit; `licence` states the terms the file is held under -
SIMION outputs are recordings of a proprietary vendor program's results.
