# ESA application example (summary values)

Public summary of a private electrostatic-analyzer study (CAD geometry and raw data are not in this repository). Values are copied from the study's stored results: channel_table.csv (32 log channels, axisymmetric CAD meridian, h=0.125 mm, 4,096 electrons per point), the fixed-code unchanged-hardware control (U=372 V, h=0.125 mm) and the selected design's energy validation (h=0.125 mm, 32,768 electrons).
